# 问题二科学审查与论文写作边界

## 可确认的事实

- 原始 `1.csv` 为 250 款啤酒、231 项化学或理化变量，`4.csv` 为同一 250 款的 50 个连续感官变量。二者 `beer` 顺序完全一致；`4.csv` 的 `beer_id` 有 213 个与 `1.csv` 精确数值不一致，源于科学计数法舍入。
- 原始 `2.csv` 与从 `1.csv` 重算的 Spearman 相关矩阵非对角项平均绝对差约 `1.61×10⁻¹⁶`。PDF 的“皮尔逊”描述与附件数值不符，应报告真实验证结果。`6.csv` 的 2200 个交叉相关值与重算结果平均绝对差约 `1.54×10⁻⁵`，故不能当独立验证集。
- 按正式算法输出 50×3=150 条关联候选。两种 bootstrap 均重跑最终选取规则；主指标还重建了化学图。200 次完整流程重采样下，正式 Top-3 的平均单项入选频率为 `0.4753`，平均集合 Jaccard 为 `0.3583`，说明唯一的前三名并不普遍稳定。旧版问题二的 bootstrap 与最终方法不一致，且把同源 `6.csv` 叫“外部校验”，均已纠正。
- 与 `8.xlsx` 中整体感官维度的 GBM MDI/SHAP 前三做**同源异法**对照，Jaccard 分别为 `0.5` 和 `0.2`。不得把该结果描述为独立数据的准确率。
- 在 12 个有明确名称的化学—感官配对中，9 个直接命名化合物进入相应 Top-3。`alcohol` 中乙醇的 Spearman 系数约 `0.817`，完整 bootstrap 频率 `1.000`；`X4vg` 中 4VG 约 `0.473`、频率 `0.945`；`lactic` 中乳酸约 `0.448`、频率 `0.585`。这些是较可解释的代表。
- `dms` 对 DMS 的直接 Spearman 仅约 `0.088`，排名 84/217；`diacetyl` 对二乙酰约 `−0.100`，排名 81/217；`t2n` 对反式-2-壬烯醛约 `−0.151`，排名 16/217。三者均未进入数据关联 Top-3。其余代理化合物只能称为相关标志，不能称为已验证的直接致味物。
- `dms` Top-3 平均频率约 `0.190`，`t2n` 约 `0.227`，`A_hops_woody` 约 `0.202`。这些维度属于低稳定性，需要在正文和结果表中清楚标注。
- 对 Top-3 做按啤酒风格去均值的敏感性检查，约 `96.7%` 保持相关方向，但仅 `44.7%` 保持绝对相关系数至少 `0.20`。风格混杂仍可能影响排名。
- 在图幂指数 `5/10/20` 和直接证据权重 `0.50/0.70/0.80` 的九组检查中，各组与主 Top-3 的平均 Jaccard 为 `0.844–1.000`。这仅说明这两项超参数在所测范围内不剧烈改变结果，不抵消重采样不稳定与机制不匹配。

## 代表性化学合理性审查

完整的并列表见 `q2_plausibility_review.csv`。此表是后验审查，**没有手工替换主 Top-3**。

- `A_hops_tropical` 的统计前三名是 DMS、香茅醇和香叶酸甲酯。其中 DMS 在 `8.xlsx` 标为 Malt 来源，且气味描述是熟蔬菜等缺陷；它与“热带酒花香”不应直接作致味联系。香叶酸甲酯的 `8.xlsx` 来源是 Hops，可作为来源相符的关联候选，但该附件并未证实它就是热带香的主因。DMS 更适合称为样本风格相关标志。
- `A_hops_noble` 的前三名是辛酸乙酯、癸酸乙酯和反式-2-壬烯醛，前两者为 Yeast 来源、第三者为 Others 来源；没有 Hops 来源成员。该组尤其不适合写成“识别出决定草本酒花香的三种物质”。
- `A_malt_all` 的前三中甲基吡嗪来自 Malt，另两个分别来自 Yeast 和 Hops；甲基吡嗪可以作为来源层面的候选，其余更可能是共同风格标志。`F_malt_all` 的前三完全没有 Malt 来源成员，也应谨慎。
- `dms`、`diacetyl`、`t2n` 三个直接命名维度的化学锚点没有进入统计前三，且前两者的直接 Spearman 绝对值低于 `0.10`。这里缺乏将代理化合物称为直接缺陷成因的依据。正文需解释感官标签噪声、阈值效应、化合物浓度区间以及风格共变均可能造成这种错位，而不能把任何一个原因写成已证事实。

## 论文可写结论

可以写“在给定样本和统计规则下识别 50 个维度各 3 个**关联候选**，在乙醇、4VG、乳酸等有明确名称的目标上观察到合理对应”。必须并列报告选择频率与同源异法对照，并说明各维差异明显。不能写“全部 Top-3 均为确定的关键致味化合物”“与标准答案高度一致”或“已通过外部验证”。附件没有完整 Top-3 金标准答案，也没有独立的干预数据。

### 方法公式

对化学 Spearman 相关系数 \(r_{uv}\) 定义图权 \(A_{uv}=\operatorname{sign}(r_{uv})|r_{uv}|^{10}\)，对角设零并按绝对行和标准化为 \(P\)。第 \(k\) 个感官维度的网络证据为 \(N_k=0.65D_k+0.25PD_k+0.10P^2D_k\)，其中 \(D_k\) 是逐化合物的样本 Spearman 系数。两类证据分别按候选池内最大绝对值归一化，并以 \(E_k=0.70|D_k|_{\mathrm{norm}}+0.30|N_k|_{\mathrm{norm}}\) 融合。逐次选取时惩罚与已入选项的最大绝对相关 \(0.15\max|r_{uv}|\)。相关符号单独保留，负相关也是统计关联，不解释成“负因果效应”。

8.xlsx 中化合物来源的“来源相符”是一个粗分类检查，不能据此证明化学机制。相应审计中，90 条麦芽/酒花/酯类目标关联里仅 34 条来自同名源类，56 条需要额外解释；共同风格、共线性和化学途径交叉都可能造成这种现象。论文应挑选少数有阈值和来源证据的例子讨论，避免对 150 个化合物逐一作机制断言。
